# 🧹 Mac Disk Cleaner

macOS 디스크 용량을 **스캔 → 카테고리별 분류 → 로컬 웹 GUI에서 선택 → 휴지통 이동**
하는 가벼운 정리 도구입니다.

- **의존성 0** — Python 3 표준 라이브러리만 사용 (pip 설치 없음)
- **안전** — 영구삭제 안 함, 휴지통으로 이동(복원 가능), 시스템 경로 보호
- **단일 파일** — `disk_cleaner.py` 하나로 스캔·웹서버·삭제 전부 처리
- **로컬 전용** — 서버는 `127.0.0.1`에만 바인드, 외부 접근 차단

---

## 요구사항

- macOS
- Python 3 (시스템에 기본 설치되어 있음)

설치할 것 없음. clone 후 바로 실행됩니다.

## 설치 & 실행

```bash
git clone https://github.com/MymiK98/mac-disk-cleaner.git
cd mac-disk-cleaner
python3 disk_cleaner.py
```

실행하면 디스크를 스캔한 뒤 브라우저가 자동으로 열립니다
(`http://127.0.0.1:8765/`). 종료는 터미널에서 `Ctrl+C`.

### 앱처럼 더블클릭으로 실행

Finder에서 더블클릭으로도 실행할 수 있습니다:

| 파일 | 동작 |
|---|---|
| **`DiskCleaner.app`** | 진짜 앱처럼 더블클릭 (독에 등록 가능). Terminal 창이 열리며 실행 |
| **`DiskCleaner.command`** | 더블클릭하면 Terminal에서 바로 실행 |

> 첫 실행 시 macOS가 "확인되지 않은 개발자"로 막으면 `.app` **우클릭 → 열기**를 한 번 하면 통과됩니다.

## 사용법

1. 카테고리를 펼쳐 정리할 항목을 체크합니다.
   - **시스템 캐시 / 개발 캐시**는 기본 선택, **대용량 / 중복**은 실수 방지를 위해 기본 해제.
2. 하단 **"선택항목 휴지통 이동 →"** 클릭 → 확인 모달에서 수락.
3. 진행바가 실시간으로 이동 상황 / 확보 용량 / 실패 항목을 보여줍니다.

## 카테고리

| 카테고리 | 대상 | 기본 선택 |
|---|---|---|
| **시스템 캐시/로그** | `~/Library/Caches`, `~/Library/Logs` 의 앱별 하위폴더 | ✅ |
| **개발 캐시** | `~/.npm`, `~/.cache`, `brew --cache`, Xcode `DerivedData`, CoreSimulator 캐시 | ✅ |
| **대용량 파일** | 홈 디렉토리 하위 500MB 이상 개별 파일 | ☐ |
| **중복/다운로드** | `~/Downloads` 내 내용이 동일한 중복 파일 (사본만) | ☐ |

시스템 캐시는 앱별 하위폴더로 분해해서 보여주므로, 보호된 캐시 하나가
나머지 삭제를 막지 않습니다.

## 안전장치

- **영구삭제 안 함** — Finder 휴지통(`~/.Trash`)으로 이동하므로 언제든 복원 가능.
- **보호 경로 차단** — `/System`, `/Library`, `~`, `~/Library` 등 핵심 경로는 삭제 거부.
- **삭제 전 확인** — 항목 수 / 총 용량 확인 모달.
- **중단 없는 배치** — 권한 거부·사라진 항목은 건너뛰고 실패/스킵 목록에 표시,
  전체 작업을 멈추거나 데이터를 복사하지 않음.
- **잠금 항목 표시** — 현재 사용자가 지울 수 없는 항목(예: root 소유)은
  🔒 로 표시하고 선택을 비활성화.

## 전체 디스크 접근 권한 (선택)

macOS는 일부 앱 캐시(Safari, HomeKit, CloudKit 등)를 **TCC**로 보호하므로
기본 상태에선 삭제가 실패합니다. 이런 항목까지 정리하려면:

1. 도구의 **"권한 설정"** 버튼 → **시스템 설정 열기**
2. 시스템 설정 → 개인정보 보호 및 보안 → **전체 디스크 접근 권한**
3. **터미널**(또는 Python)을 추가하고 켠 뒤 도구를 재실행

권한이 없어도 보호되지 않은 캐시는 정상 삭제되고, 보호 항목만 실패로 표시됩니다.
root 소유 항목은 전체 디스크 접근 권한으로도 안 되며, 터미널에서
`sudo rm -rf <경로>` 로만 삭제할 수 있습니다(권한 설정 패널에 명령 안내 표시).

## 동작 방식

```
[스캔]   카테고리별 파일 목록 + 크기 수집 → JSON 인벤토리
   ↓
[웹서버] 127.0.0.1 바인드 → 브라우저 자동 오픈 → HTML+데이터 전달
   ↓
[삭제]   체크박스 선택 → POST /delete → 항목별 휴지통 이동(NDJSON 스트리밍)
         → 진행바 실시간 갱신
```

- 삭제는 Finder 자동화(osascript) 대신 `~/.Trash`로 **직접 이동**(`os.rename`)
  하므로 권한 프롬프트로 멈추지 않습니다.
- 같은 볼륨이면 즉시 이동, 다른 볼륨일 때만 복사+삭제로 폴백합니다.
