# Mac Disk Cleaner

macOS 디스크 용량을 스캔해 카테고리별로 분류하고, 로컬 웹 GUI에서
체크박스로 선택한 항목을 **휴지통으로 이동**(되돌리기 가능)합니다.

의존성 0 — Python 3 표준 라이브러리만 사용. pip 설치 없음.

## 요구사항

- macOS, Python 3 (기본 설치됨)

## 실행

```bash
python3 disk_cleaner.py
```

"스캔 중..." 후 브라우저가 자동으로 열립니다(`http://127.0.0.1:8765/`).
카테고리를 펼쳐 항목을 선택한 뒤 **"선택항목 휴지통 이동"** 클릭 →
확인 모달에서 수락하면 휴지통으로 이동합니다.
종료는 터미널에서 `Ctrl+C`.

## 카테고리

| 카테고리 | 대상 | 기본 선택 |
|---|---|---|
| 시스템 캐시/로그 | `~/Library/Caches`, `~/Library/Logs` 의 앱별 하위폴더 | ✅ |
| 개발 캐시 | `~/.npm`, `~/.cache`, `brew --cache`, Xcode `DerivedData`, CoreSimulator 캐시 | ✅ |
| 대용량 파일 | 홈 하위 500MB 이상 개별 파일 | ☐ |
| 중복/다운로드 | `~/Downloads` 내 내용이 동일한 중복 파일 (사본만) | ☐ |

대용량·중복 카테고리는 실수 방지를 위해 기본 해제 상태입니다 — 직접 켜야 선택됩니다.

## 안전장치

- **영구삭제 안 함.** Finder 휴지통으로 이동하므로 언제든 복원 가능.
- 시스템 핵심 경로(`/System`, `/Library`, `~`, `~/Library` 등)는 보호 목록으로
  삭제 차단.
- 삭제 전 항목 수 / 총 용량 확인 모달.
- 로컬 전용: 서버는 `127.0.0.1`에만 바인드되어 외부 네트워크 접근 불가.
- 권한 거부 항목은 건너뛰고 실패 목록에 표시 — 절대 중단/복사하지 않음.

## 전체 디스크 접근 권한 (선택)

macOS는 일부 앱 캐시(Safari, HomeKit, CloudKit 등)를 보호하므로 기본 상태에선
삭제가 "권한 거부"로 실패합니다. 이런 항목까지 정리하려면:

1. 시스템 설정 → 개인정보 보호 및 보안 → **전체 디스크 접근 권한**
2. **터미널**(또는 Python)을 추가하고 켜기
3. 도구 재실행

권한이 없어도 보호되지 않은 캐시는 정상 삭제되고, 보호 항목만 실패로 표시됩니다.
